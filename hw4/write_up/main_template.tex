\begin{problem}
The hash function $h_i(x) = (x + a_i) \bmod w$ is not good. For a given $w$, any group of elements
that differ by a multiple of $w$ will hash to the index in every row and collide. For example, if 
$w = 10$, then the elements $3, 13, 23, \ldots$ will collide in every row.

For a given row $i$\\
$h_i(3) = (3 + a_i) \bmod 10$\\
$= h_i(13) = (13 + a_i) \bmod 10$\\
$= h_i(23) = (23 + a_i) \bmod 10$\\
Each of these elements will hash to the same index in row $i$.

\end{problem}
